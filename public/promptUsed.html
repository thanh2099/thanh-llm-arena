4. Passkey Authentication & Security Architecture

  • Master Passkey: thanh2099
  • Settings Modal Protection: Clicking 🔒 ADMIN in the top banner or bottom of the sidebar prompts the user for the passkey. Incorrect entries surface an inline shake warning.
  • Session Caching: Successful entry persists authentication in sessionStorage (thanh_admin_auth_v1: "true") until the user clicks 🔒 LOCK or closes the browser tab.
  • Backend Endpoint Hardening: GET /api/providers/status strictly enforces the header x-admin-passkey: "thanh2099". Requests without it return HTTP 401 Unauthorized.
  • Key Isolation: Provider keys are loaded securely from .env on the server and are never exposed in the client bundle. Users may also provide runtime client overrides in the settings modal.

5. Dual-Cloud Deployment Blueprint (Render + Netlify)

The platform separates static frontend delivery from long-running stateful SSE streaming to maximize performance and eliminate cold starts.

Step 1: Render.com Backend Web Service

  1. Create a new Web Service on Render connected to the GitHub repository.
  2. Select Node runtime, branch master.
  3. Build Command: npm install.
  4. Start Command: npm start (executes tsx src/server/index.ts bound to 0.0.0.0).
  5. Set Environment Variables: OPENCODE_GO_API_KEY, GEMINI_API_KEY, OPENROUTER_API_KEY.

Step 2: Netlify Frontend CDN

  1. Link the GitHub repository on app.netlify.com.
  2. Build Command: npm run build, Publish Directory: dist.
  3. Configure netlify.toml and public/_redirects:
    /api/* https://thanh-llm-arena.onrender.com/api/:splat 200! /* /index.html 200
  4. Automatic runtime discovery in src/client/lib/apiConfig.ts handles direct CORS connections as well as proxy redirects.

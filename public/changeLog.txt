VERSION 1.5.0 — Latency, Cold-Start & Streaming Performance Optimization
Date: 2026-10-26
Revisions: 20b5a2f, 9579134
--------------------------------------------------------------------------------
[Revision 20b5a2f | 2026-10-26]
- Added automatic 24/7 Render self-keepalive heartbeat in src/server/index.ts
  that pings RENDER_EXTERNAL_URL/api/health every 12 minutes to prevent
  Render free-tier containers from sleeping.
- Extended the upstream endpoint circuit-breaker cooldown duration to 10 minutes
  (600,000ms) and tightened first-token failover timeout to 2.8 seconds.

[Revision 9579134 | 2026-10-26]
- Added <link rel="preconnect"> and <link rel="dns-prefetch"> in index.html for
  https://thanh-llm-arena.onrender.com to eliminate DNS + TLS handshake latency.
- Added ultra-fast GET /api/health endpoint (<1ms response) in
  src/server/routes/chat.ts.
- Added automatic client-side backend pre-warming on page load and 4-minute
  keep-alive pings while the tab is visible in src/client/App.tsx.
- Implemented in-memory Endpoint Circuit Breaker in src/server/routes/chat.ts
  to bypass failed or timed-out upstream endpoints on subsequent requests with
  0ms wasted delay.
- Updated Space Bunny primary OpenCode Go target model to minimax-m3.1-flash-free
  (replacing deprecated space-bunny model ID that returned HTTP 410).
- Updated Auto smart router (classifyAutoModel) to route general text queries
  directly to GLM-5.3-Flash on OpenCode Go (~680ms TTFT) and added OpenCode Go
  secondary fallbacks across models.
- Debounced localStorage thread serialization (saveThreads) to 400ms during
  active token streaming in src/client/App.tsx to prevent main-thread UI blocking.
